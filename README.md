# PostgreSQL Practice

A learning repository for PostgreSQL and relational database concepts, built as part of my backend/PERN stack practice.

## What's inside

- [01 — Introduction](./01-Introduction/) — PostgreSQL, its architecture, installation, pgAdmin, and psql notes
- [02 — SQL](./02-SQL/) — SQL basics, filtering, joins, aggregation, and query examples
- [Database Design & Constraints](./Database%20Design%20%26%20Constraints/) — keys, constraints, and design examples
- [Setup notes](./setup.md) — setup references and learning notes

## Topics covered

- Databases, tables, data types, and CRUD
- Filtering, sorting, and querying
- Primary keys, foreign keys, relationships, and joins
- Aggregation, GROUP BY, and HAVING
- Constraints and basic database design

## Tools

- PostgreSQL
- pgAdmin 4
- psql

The files are study notes and SQL exercises; they are not a deployable application.
